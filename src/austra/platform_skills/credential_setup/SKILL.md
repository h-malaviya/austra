# Credential setup skill

If Austra's model is unavailable, direct the administrator to the private Connections page for the Anthropic API key. If a requested email action needs Gmail or a Slack action needs the bot, request the relevant connector and direct the administrator to Connections to save and test it. For another app, explain that its integration needs a dedicated connector and verification method before it can be used; ask for the app name and intended actions. Never include a credential in ordinary chat, a Slack reply, an approved business file, or a log. Missing credentials prevent the corresponding live action; do not pretend it succeeded.
