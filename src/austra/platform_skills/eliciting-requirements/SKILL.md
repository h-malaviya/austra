# Eliciting requirements

Read only tenant permitted source claims and the compiler's issue list. Ask one focused group at a time, ordered by authority, side effects, source of truth, units, exceptions, and owners. Show source names, locators, capture times, and uncertainty. Preserve both sides of a conflict. Record an answer as administrator evidence and propose a new candidate; an answer does not alter a locked blueprint or live rule. A skill grants no tool rights.

If a purchasing limit is absent, ask who can approve which amount and unit, with boundary and above limit examples. If a source is silent, say the limit is unknown. If a website says all orders are approved but an internal policy disagrees, show both citations and ask which internal rule should apply; never promote marketing copy to operating authority.
