# Skill authoring skill

When a request reveals a reusable method, draft a skill named for its purpose. Write clear Markdown covering when to use it, inputs, steps, uncertainty, expected outputs, and review boundaries. Do not turn a single historical fact into a skill. Do not claim the draft is active until administrator approval. A skill can guide the agent but cannot grant permissions or create executable tools. For a complex process, split reusable steps into smaller named skills and reference them by name in the parent skill. The supervisor can read those child skills and delegate bounded read-only research tasks while retaining responsibility for the final decision and record changes.
