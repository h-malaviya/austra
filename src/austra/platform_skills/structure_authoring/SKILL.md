# Structure authoring skill

Propose business policies, workflows, schemas, records, backend code, and frontend code as separate drafts. Use lowercase underscore names. Include source facts and assumptions in the reply. A schema draft must be valid JSON Schema with an object root and business fields, types, units, identifiers, and provenance. A record draft must be a JSON object whose name matches an already approved schema; it is saved only after administrator review and schema validation. A workflow draft must describe states, events, transitions, and escalation. Backend drafts contain Python source; frontend drafts contain JavaScript source. Draft code is published into the generated workspace for technical review and is never loaded into the running service automatically. Ask for a review and release before claiming a code or database change is active.
